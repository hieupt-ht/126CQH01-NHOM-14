# Visual Review Checklist

## Source and scope

- [ ] `writing-block.md`, Issue #1 and the relevant PRD section were read.
- [ ] The reviewed screen and states exist in the confirmed scope.
- [ ] No unapproved control, feature, palette or copy was introduced.

## Visual system

- [ ] Midnight Aurora background/surface hierarchy is used.
- [ ] Colors reference approved CSS variables only.
- [ ] Primary CTA uses the approved gradient; secondary controls remain restrained.
- [ ] Cards, borders, radii, shadows and spacing match the shared language.
- [ ] Artwork is not tinted, cropped incorrectly or covered by decorative neon effects.

## Behavior and states

- [ ] Default, focus, hover, disabled and keyboard states were checked.
- [ ] Loading, empty, error, success and relevant job states were checked.
- [ ] Destructive actions confirm intent and do not claim physical deletion prematurely.
- [ ] No duplicate generation or automatic retry is triggered by navigation/reload.

## Responsive and accessibility

- [ ] 360px, 768px, 1280px and 1536px views were checked where relevant.
- [ ] No horizontal overflow exists.
- [ ] Keyboard, focus, dialog Escape/focus return and reduced motion were checked.
- [ ] Status is understandable without color alone and contrast is acceptable.

Record screenshots, viewport sizes, route, data source and unresolved deviations in the review report.
