# Style picker reference assets

These are static illustrative previews, not FLUX results or predictions for a user's prompt.

- `watercolor.svg`, `oil-painting.svg`, `comic.svg`: original vector demo illustrations authored in this repository on 2026-11-07. No external image download or provider call. Their artwork colors are image content, not UI tokens.
- Photographic preview reuses `../images/home/showcase-cinematic-portrait.jpg`; 3D reuses `../images/home/hero-3d-glass.jpg`. Provenance and previously recorded Unsplash terms are in that directory's README; no new license verification is claimed.
- Cinematic, storybook and anime previews reuse crops of the user-supplied `../reference/dashboard-reference.jpg`; original provenance is in its README. These references illustrate broad visual directions, not model fidelity guarantees.

All cards are explicitly labeled as illustrative in the picker. Selection only updates presentation state; it does not start inference.
